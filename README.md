# 51 单片机课程实验代码存档

福州大学 · 单片机课程实验（AT89C51 / AT89C52）

开发环境：Keil uVision5（C51 V9.59）。部分实验在 Proteus 8 下做仿真验证。

## 实验目录

| 序号 | 目录 | 内容 |
| --- | --- | --- |
| 01 | `01-led-blink` | GPIO 输出，点亮第一个 LED |
| 02 | `02-led-flow` | 循环移位实现流水灯 |
| 03 | `03-seg-static` | 静态数码管显示 |
| 04 | `04-seg-dynamic` | 动态扫描驱动多位数码管 |
| 05 | `05-key-independent` | 独立按键检测与软件消抖 |
| 06 | `06-key-matrix` | 4×4 矩阵键盘扫描，键值送数码管显示 |
| 07 | `07-ext-int0` | 外部中断 0 的触发与响应 |
| 08 | `08-timer0` | 定时器 0 的工作方式与初值计算 |
| 09 | `09-uart` | 串口通信，波特率配置与收发 |

## 说明

- 代码在普中科技（PRECHIN）开发板配套例程的基础上，按课程要求完成实验并调整了参数与逻辑
- `.hex`、`.obj`、`Listings/` 等编译产物不纳入版本管理，见 `.gitignore`
- 源码统一使用 UTF-8 编码。Keil 中若中文注释显示为乱码，可在 `Edit → Configuration → Editor → Encoding` 中改为 UTF-8
